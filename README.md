# Kobe Bryant Career Analysis (1996–2016)

End-to-end data analysis tracking Kobe Bryant's 20-season career with the Lakers, combining SQL documentation with a custom purple-and-gold Tableau dashboard.

## Overview
* **Dataset:** Kobe Bryant's complete 20-year career stats.
* **SQL:** Analytical queries documenting the data logic and metric breakdown.
* **Tableau:** Interactive dashboard featuring small multiples, scoring efficiency, and defensive impact.

## Structure
* `sql/` - Analytical SQL scripts.
* `dashboard/` - Tableau visualization workbook.
